World Wide Web

I learned that the Web is a system of interconnected webpages and websites that can be accessed using the Internet.

This means that the World Wide Web is a collection of webpages and websites connected by links, which allow you to jump from one place to another using the Internet.

Note: The World Wide Web was created by Tim Berners-Lee in 1989.

Components of the Web

HTML

HyperText Markup Language, commonly known as HTML, is the standard markup language used to create and structure webpages or websites.

HTML is not a programming language because it does not perform programming tasks such as making decisions or calculations. It is a markup language because it uses markup elements and tags to structure and describe content.

URLs

Uniform Resource Locators, also called URLs, are addresses used to identify and locate a specific webpage or resource.

There is a difference between URLs, IP addresses, and domain names, but most beginners confuse them.

A URL is the full address used to locate a specific webpage or resource on the Web. A URL can contain different parts, including a protocol, domain name, and a path to a specific resource.

While the domain name is the unique name used to identify a website. It is simply a name that people can use to identify a website.

The IP address is a numerical address used to identify a device on a network. DNS can resolve a domain name to an IP address so that the browser can communicate with the appropriate web server.

HTTP

HyperText Transfer Protocol, also known as HTTP, is the protocol that governs data transfer between a web server and a user's web browser.

It is a set of rules that both your browser and the server follow when transferring data. There is a difference between HTTP and HTTPS.

HTTP normally transfers data without encryption, while HTTPS is the secure version that uses encryption to protect data being transferred between the browser and the server.

Web Servers and Web Browsers

A web server is a computer that stores and delivers webpages or content to users, while a web browser is a software application like Chrome, Microsoft Edge, Firefox, etc. that interprets and displays webpages for the user.

I'm going to explain how the Web and its components actually work using a real-life example.

For Example

You were given a research assignment on Organic Chemistry. When you reach home, you decide to Google the assignment. Therefore, you pick up your computer or phone, connect it to Wi-Fi, open your browser, and search for Organic Chemistry.

After a few seconds of searching, your browser will then list possible webpages and resources that have similar content relating to what you searched for.

After choosing one of the URLs, your browser will send an HTTP request to the web server where the website containing the information that you need is stored.

Before the browser can communicate with the server using the domain name, DNS can resolve the domain name to an IP address.

Once the IP address is known, the browser can communicate with the appropriate web server, which locates the requested webpage and transfers the requested files back to your browser using HTTP and the Internet as the transport network.

After your browser receives the files, it will display the webpage on your screen by rendering the HTML, CSS, and JavaScript used to build the webpage.
